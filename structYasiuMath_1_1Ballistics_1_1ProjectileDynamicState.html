Detailed Description

template<typename T>
struct YasiuMath::Ballistics::ProjectileDynamicState< T >

Ballistic state. Can move in time with DiscreteStep function.

Self-sufficient to predict next state with DiscreteStep and AutoStep

Warning
AirFrictionCoeff must be within <0, 1> range, otherwise model will not be correct or could crash.

Step function. O(1) for AirDrag=0.

Iterative prediction for models with AirDrag > 0 Loop count is N = QueryTime / DeltaTime

Note

Last step has very small DeltaTime depending on math error
