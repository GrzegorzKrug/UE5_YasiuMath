template<typename T>
T YasiuMath::Rotation::NormalizeAngleToPeriod ( T angle,
T period = 360.f )

Normalize angle to range <0, period>. Unit independent.

Normalization removes any excess periods.

Angle can be negative. Period must be > 0

Note
Example:
Angle = -12, Period = 10
Result -> 8
